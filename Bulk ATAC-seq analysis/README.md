## Bulk ATAC-seq analysis

- [AccessibilityVsExpression.ipynb](AccessibilityVsExpression.ipynb) Google colab notebook comparing differential peaks to differential expression

- [DiffBind.Rmd](DiffBind.Rmd) R markdown, imports .bam from nextflow, performs DiffBind (differential accessibility) analysis and annotates peaks. This file was heavily based off of Param Singh's github: [DiffBind_Deseq2.R](https://github.com/SinghLabUCSF/Diapause-multiomics/blob/master/3_ATAC-seq/2_Analysis/DiffBind_Deseq2.R) and [annotate-peaks_ChIPseeker.R](https://github.com/param-p-singh/Diapause-multiomics/blob/master/3_ATAC-seq/2_Analysis/annotate-peaks_ChIPseeker.R)
