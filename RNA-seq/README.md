## RNA-seq preprocessing

This is the script and a paramter file used to run the NextFlow RNA seq pipeline.

More information on using version 3.12.0 of nf-core/rnaseq can be found [here](https://nf-co.re/rnaseq/3.12.0)

The input to nfjob.sh also includes a samplesheet.csv (omitted here), which contains the various paths to each FASTQ.
