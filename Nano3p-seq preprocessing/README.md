## Nano3p-seq preprocessing

These are the scripts used to go from pod5 files to a dataframe that contains each read aligned to a gene, its estimated polyT tail length, and its composition.

I adapted these scripts minimally, they are all from the [Novoa Lab's github](https://github.com/novoalab/polyTailor)

and their associated manuscript:

Begik, O., Pryszcz, L.P., Niazi, A.M. et al. Nano3P-seq: charting the coding and noncoding transcriptome at single-molecule resolution. Nat Protoc 20, 3607–3628 (2025). https://doi.org/10.1038/s41596-025-01205-0
