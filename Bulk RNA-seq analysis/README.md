## Bulk RNA-seq analysis

- [DifferentialGeneExpression.Rmd](DifferentialGeneExpression.Rmd) R Markdown file of a basic differential gene expression comparison and associated summary plots.
- [Overrepresentation.ipynb](Overrepresentation.ipynb) Google colab notebook of an example of an overrepresentation analysis for GO, KEGG, and Wiki pathways. This example looks into the portion of the hypoxia induced gene expression program that is in part, dependent on _tent5ba_ expression.
- [EISA.Rmd](EISA.Rmd) R Markdown file of exon splice analysis of bulk RNA-seq data from alignment, differential testing, to plotting and exporting. This markdown file was based on this [tutorial](https://fmicompbio.github.io/eisaR/articles/eisaR.html) from this paper:


`Gaidatzis D, Burger L, Florescu M, Stadler MB. Analysis of intronic and exonic reads in RNA-seq data characterizes transcriptional and post-transcriptional regulation. Nat Biotechnol. 2015 Jul;33(7):722-9. doi: 10.1038/nbt.3269. Epub 2015 Jun 22. Erratum in: Nat Biotechnol. 2016 Feb;34(2):210. doi: 10.1038/nbt0216-210a.. Florescu, Maria [Deleted]. PMID: 26098447.`
