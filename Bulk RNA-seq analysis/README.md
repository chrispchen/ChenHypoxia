## Bulk RNA-seq analysis

- [DifferentialGeneExpression.Rmd](DifferentialGeneExpression.Rmd) R Markdown file of a basic differential gene expression comparison and associated summary plots.
- [Overrepresentation.ipynb](Overrepresentation.ipynb) Google colab notebook of an example of an overrepresentation analysis for GO, KEGG, and Wiki pathways. This example looks into the portion of the hypoxia induced gene expression program that is in part, dependent on _tent5ba_ expression.
- [KCNvsHypoxia.ipynb](KCNvsHypoxia.ipynb) Google colab notebook comparing KCN induced and hypoxia induced gene expression via a scatterplot.
- [EISA.Rmd](EISA.Rmd) R Markdown file of exon splice analysis of bulk RNA-seq data from alignment, differential testing, to plotting and exporting. This markdown file was based on this [tutorial](https://fmicompbio.github.io/eisaR/articles/eisaR.html) from this [paper](https://www.nature.com/articles/nbt.3269):


> Gaidatzis, D., Burger, L., Florescu, M. et al. Analysis of intronic and exonic reads in RNA-seq data characterizes >transcriptional and post-transcriptional regulation. Nat Biotechnol 33, 722–729 (2015). https://doi.org/10.1038/nbt.3269
