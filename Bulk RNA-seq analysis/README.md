## Bulk RNA-seq analysis

- [DifferentialGeneExpression.Rmd](DifferentialGeneExpression.Rmd) R Markdown file of a basic differential gene expression comparison and associated summary plots.
- [Overrepresentation.ipynb](Overrepresentation.ipynb) Google colab notebook of an example of an overrepresentation analysis for GO, KEGG, and Wiki pathways. This example looks into the portion of they hypoxia induced gene expression program that is in part, dependent on _tent5ba_ expression.
