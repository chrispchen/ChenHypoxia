## RNA-seq preprocessing

This is the script and a paramter file used to run the NextFlow RNA seq pipeline.

More information on using version [3.12.0 of nf-core/rnaseq](10.5281/zenodo.1400710) can be found [here](https://nf-co.re/rnaseq/3.12.0)

`nfjob.sh` requires a samplesheet.csv (omitted here), containing the various paths to each FASTQ.
