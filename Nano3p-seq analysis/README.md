## Nano3p-seq analysis

* [PolyALengthComparisonToBegik2023.ipynb](PolyALengthComparisonToBegik2023.ipynb): Google colab notebook comparing the poly(A) tail lengths estimated from the Nano3p-seq normoxia 6 hpf datasets captured in our study with the original Nano3p-seq dataset (same stage). The comparison data is from Figure 3G source data from this paper:
  
>Begik, O., Diensthuber, G., Liu, H. et al. Nano3P-seq: transcriptome-wide analysis of gene expression and tail dynamics using >end-capture nanopore cDNA sequencing. Nat Methods 20, 75–85 (2023). https://doi.org/10.1038/s41592-022-01714-w

* [DifferentialPolyadenylation.ipynb](DifferentialPolyadenylation.ipynb): Google colab notebook containing a function to conduct differential polyadenylation between two groups. This notebook compares wildtype embryos in Normoxia 6hpf vs. Hypoxia 18hrs as an example use case
