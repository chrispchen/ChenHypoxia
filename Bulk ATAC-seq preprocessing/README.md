## Bulk ATAC-seq preprocessing

This is the script and a paramter file used to run the NextFlow ATAC seq pipeline.

More information on using version [2.0 of nf-core/atacseq](10.5281/zenodo.2634132) can be found [here]([https://nf-co.re/rnaseq/3.12.](https://nf-co.re/atacseq/2.0)0)

The input to nfjobATAC.sh also includes a samplesheet.csv (omitted here), which contains the various paths to each FASTQ.
