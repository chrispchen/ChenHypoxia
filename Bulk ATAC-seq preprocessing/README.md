## Bulk ATAC-seq preprocessing

This is the script and a paramter file used to run the NextFlow ATAC seq pipeline.

More information on using version [2.0 of nf-core/atacseq](10.5281/zenodo.2634132) can be found [here](https://nf-co.re/atacseq/2.0)

`nfjobATAC.sh` requires a samplesheet.csv (omitted here), containing the various paths to each FASTQ.
